# 누비자 대여·반납 원자료 수집과 검증

## 현황

| 대상 | 크기(bytes) | SHA256 | 레코드 수 | 출발기간·한계 |
|---|---:|---|---:|---|
| 2025 CSV | 237,421,293 | `e4b269df2bf018095f358eb56067464c6554fb41713ad1cd9a5765affb3606dc` | 4,419,063 | 2025-01-01~12-31. 7월 전체 누락, 11개 출발월만 존재 |
| 2024 CSV | 245,633,968 | `8146617ccfa69430cfbb4c570b750df9456667dd72cba374b4396cee34e3a51f` | 4,582,332 | 2024-01-01~12-31. 12개 출발월 |
| 2023 CSV | 216,640,346 | `973f82b32803f9a72d26c845c2be6f5a783836881f603e81783c54561b3cad4b` | 4,066,540 | 2023-01-01~12-31. 12개 출발월 |
| 2022 ZIP | 미완료(기대 159,003,222) | - | 미확정 | 전송이 두 차례 끊겨 부분파일만 있음 |

- 3개 CSV는 CP949, 7열, 빈 값 0이다. 원본은 수정하지 않았다.
- 2025년 7월은 수요 0으로 읽거나 보간하지 않고 학습·평가에서 제외한다. 원인(등록 누락, 추출 누락, 서비스 정지)은 확인하지 못했다.
- 월이 존재해도 월 내부 날짜·건의 완전성까지 보장하지는 않는다.
- SHA256은 로컬 무결성 확인용이며 제공기관 체크섬과 대조한 값은 아니다.

## 출처

- 제공 페이지: https://www.data.go.kr/data/15126280/fileData.do (경상남도 창원시 환경정책과, 무료, 이용허락범위 제한 없음)
- 접근 경로: 제공 페이지 → 주기성 과거 데이터 → 해당 연도 → 데이터 다운로드 (2022년은 ZIP)
- 로그인·활용신청 없이 공식 첨부 URL로 내려받았다.

## 2025년 품질 점검

- 완전 중복 0, 유효하지 않은 날짜시간 0, 음수 대여시간·날짜 역전 0, 0초 대여 506건
- 24시간 초과 대여 3,195건(7일 이하 3,019, 7~30일 126, 30일 초과 50), 최대 15,667,437초. 원인은 확인하지 못했다
- 도착일 최대값이 2026-04-19로, 출발연도를 넘겨 반납된 건이 있다
- 터미널 코드는 출발 462종, 도착 463종이다. 현재 운영 터미널 수로 읽으면 안 된다
- 2025년 터미널 시트와 맞지 않는 코드: 출발 329 1건, 도착 7 107건·329 1건. 좌표·명칭을 추정해 잇지 않았다
- 심화 검증은 2025년만 했다. 2023·2024는 기본 전체 검증(행수·열 수·빈 값·날짜 범위)까지다

## 2022년 자료

공식 원본 파일명은 `20~22 터미널 대여반납정보.zip`이다. 자동 내려받기는 read timeout과 서버 IncompleteRead로 실패했고, 서버가 Range 요청에 전체 파일(200)로 답해 이어받기도 할 수 없었다. 부분파일(약 58MB)은 `.partial`로 보관하며 분석에 쓰지 않는다. 브라우저로 직접 내려받아 기대 크기와 ZIP 정상 여부를 확인하기 전에는 2022년을 확보한 것으로 쓰지 않는다.

## 재현

프로젝트 루트에서 실행한다. 수집이 끝나기 전에 다시 실행하지 않는다.
```powershell
python scripts/collection/nubija_trips_collect_2025.py   # 2025 단독 수집
python scripts/collection/nubija_trips_collect.py        # 2024→2023→2022 순차 수집
python scripts/collection/nubija_trips_validate.py       # 원본 스트리밍 검증
python scripts/collection/nubija_trips_quality_2025.py   # 2025 심화 검증
```
- 완료 조건은 HTTP 성공, 수신 bytes와 Content-Length 일치, 수신 중 계산한 SHA256 기록이며, 이후 `.partial`을 최종 확장자로 바꾼다
- 검증은 CSV를 순차로 읽고 전체를 메모리에 올리지 않는다. 결측은 빈 문자열·공백 셀이고 날짜 범위는 원문 문자열의 최소·최대다
- 심화 검증은 SQLite 임시 DB에서 7개 필드 전체 일치로 중복을 센다
- 환경: Python 3.14.5, requests 2.34.2, pandas 2.3.3, openpyxl 3.1.5
